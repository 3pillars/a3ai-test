# IHSS + Benefits Cheat Sheet — Live-In Provider Income

**Context:** How IHSS "live-in provider" wages are treated across the major programs.
Relevant if a parent is Andy's IHSS provider and the family lives in the same home.

> ⚠️ **Verify before relying on this.** Web search was off when this was written — content is
> from established policy (IRS Notice 2014-7, CA CDSS/DHCS guidance), but rules and dollar
> figures change. Confirm with the county worker or a benefits navigator (211 Santa Clara).

**The one thing that controls everything:** Does the IHSS *provider* live in the same home
as the IHSS *recipient*? If yes → "live-in provider," and the difficulty-of-care exclusion
(IRS Notice 2014-7) is in play. If no → wages generally count as normal earned income.

---

## Quick-reference table

| Program | Does live-in IHSS income count? | Notes |
|---|---|---|
| **CalFresh (SNAP)** | **No — excluded** | Live-in provider IHSS wages are exempt for both the income test and the benefit amount. |
| **Medi-Cal (MAGI)** | **Generally excluded** — but only if NOT reported as taxable wages | Follows federal tax treatment. If the income is excluded from your federal AGI (2014-7), it's excluded from MAGI Medi-Cal too. |
| **CalWORKs** | **Counts (usually)** | CalWORKs treats IHSS wages as earned income; the 2014-7 exclusion does **not** automatically carry over. Confirm with worker. |
| **Federal & CA income tax** | **Excludable from gross income** | Under Notice 2014-7 you can exclude live-in difficulty-of-care payments from taxable wages. |
| **EITC / CalEITC** | **Your choice — can elect to include** | You may *elect* to count the excluded pay as earned income to qualify for/boost EITC. Run it both ways. |
| **Social Security / payroll (FICA)** | Often exempt when parent provides care to child, or spouse to spouse | Parent-provider-for-minor-child and spouse-for-spouse relationships are commonly FICA-exempt. |

## The key rules, expanded

**1. CalFresh — excluded (best-case, clean rule)**
- Live-in provider IHSS wages don't count. A family that looks over-income on paper can
  qualify once IHSS is removed.
- If a worker counts it anyway, cite the **live-in provider exclusion / IRS Notice 2014-7**
  and ask to escalate. Known point of confusion.

**2. Medi-Cal — follows your tax treatment**
- MAGI Medi-Cal starts from federal AGI. If you exclude the IHSS pay under 2014-7 (so it's
  not in your AGI), it's not counted for Medi-Cal either.
- The catch: it has to actually be excluded on your return. If you reported it as taxable
  wages, it can flow into MAGI.

**3. CalWORKs — usually counts**
- Different rulebook. CalWORKs generally treats IHSS as earned income. Don't assume the
  CalFresh exclusion applies — ask the worker specifically.

**4. Taxes — the SOC 2298 form is the lever**
- File **SOC 2298** (Live-In Self-Certification) with IHSS/CDSS so wages are reported as
  excluded from the start — keeps them off your W-2 box 1 taxable wages.
- If you already had them taxed, you can still exclude on the return and/or amend.

**5. EITC — the strategic choice**
- Excluded 2014-7 income can be **elected** back in as earned income *for EITC purposes only*.
- For a lower-income family this can mean a bigger refund. Worth modeling both ways at tax time.

## Action checklist
- [ ] Confirm who the IHSS provider is and that provider + recipient share the home.
- [ ] File **SOC 2298** if not already on file (controls tax + downstream MAGI treatment).
- [ ] On CalFresh application/recert: state IHSS is live-in provider income → excluded.
- [ ] For CalWORKs: ask the worker directly how they're treating it (don't assume).
- [ ] At tax time: run EITC/CalEITC both ways (include vs exclude the IHSS pay).
- [ ] Use **211 Santa Clara** or a free benefits navigator to sanity-check the whole stack.
